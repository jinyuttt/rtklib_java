# 海潮负荷模块技术参考

> **包路径**：`org.rtklib.java.otl`
> **功能**：从FES2004全球海潮模型直接提取BLQ海潮负荷系数，或计算任意时刻的OTL位移时间序列
> **算法来源**：球谐综合移植自PRIDE-PPPAR（Zhang Chuanyin）的OLoadDFlu.f90/LTideFlupnm.f90链；Legendre函数移植自Belikov改进递推（BelPnmdt.f90）；天文参数移植自ASTRO5（R.D. Ray, NASA/GSFC）

---

## 1. 模块总览

```
FES2004S1.dat ──加载──> Fes2004Record[] ──球谐综合──> BLQ系数 [3][11][2]
                                                        │
                                                        ├─ BlqWriter → 标准BLQ文件
                                                        │
                                                        └─ 谐波合成 → 位移时间序列 [epoch][4]
```

| 类 | 职责 |
|----|------|
| `BlqExtractor` | 核心提取器：BLQ系数提取 + 位移时间序列计算 |
| `BlqWriter` | 标准BLQ格式文件输出 |
| `BlqConsts` | 物理常数、11个分潮名称与Doodson数 |
| `Fes2004Loader` | 加载FES2004S1.dat球谐系数 |
| `Fes2004Record` | FES2004单条记录（Doodson数、阶数、C+/C-振幅相位） |
| `SphericalHarmonic` | 归一化缔合Legendre函数及其一阶/二阶导数 |
| `AstroArg` | 天文参数（ASTRO5）、节点改正（CalcTidefu/BiasTide）、Doodson解码 |
| `LoveNumberLoader` | 加载Farrell Love数表 |
| `FarrellLoveNumbers` | Love数数据容器 |
| `Main` | 命令行入口 |

## 3. BLQ系数提取

### 3.1 API

```java
BlqExtractor extractor = new BlqExtractor();
double[][][] blq = extractor.extract(latDeg, lonDeg);
```

### 3.2 返回值结构

```
double[3][11][2]
  ├─ [0] 径向(Radial)分量
  ├─ [1] 西向(West)分量
  └─ [2] 南向(South)分量
      ├─ [c] 第c个分潮 (0=M2, 1=S2, ..., 10=Ssa)
      │   ├─ [0] 振幅 (mm)
      │   └─ [1] 相位 (deg, 0~360)
```

### 3.3 算法流程

1. **坐标转换**：大地坐标 → 地心坐标（WGS84椭球）
2. **球谐综合**：对每个分潮，在FES2004球谐系数中匹配Doodson数，计算复数求和
3. **Love数改正**：使用hₙ（径向）和lₙ（水平）Farrell Love数
4. **分量分解**：从复数结果提取径向/西向/南向的振幅和相位

## 4. 位移时间序列计算

### 4.1 API

```java
double[][] disp = extractor.extractDisplacement(latDeg, lonDeg,
                                                 startMjd, endMjd, intervalSec);
```

### 4.2 参数说明

| 参数 | 类型 | 说明 |
|------|------|------|
| `latDeg` | double | 纬度（度，北正） |
| `lonDeg` | double | 经度（度，东正） |
| `startMjd` | double | 起始时间（MJD，UTC） |
| `endMjd` | double | 结束时间（MJD，UTC） |
| `intervalSec` | double | 采样间隔（秒） |

### 4.3 返回值结构

```
double[numEpochs][4]
  └─ [epoch]
      ├─ [0] 时间 (MJD)
      ├─ [1] 东向位移 (mm)
      ├─ [2] 北向位移 (mm)
      └─ [3] 垂直位移 (mm)
```

### 4.4 算法流程

对每个历元：
1. **天文参数**：`AstroArg.computeAstr(mjd)` 计算6个Doodson参数
2. **节点改正**：`AstroArg.calcTidefu(mjd, doodson)` 计算振幅因子df和相位改正du
3. **球谐展开**：逐阶逐次求和，使用Love数hₙ/lₙ
4. **ENU位移**：分别计算东向、北向、垂直位移

## 6. 命令行使用

### 6.1 构建

```bash
cd rtklib-otl
mvn package
```

生成 `target/rtklib-otl-2.1.1.jar`（含FES2004数据和Love数的fat jar）。

### 6.2 运行

```bash
java -jar target/rtklib-otl-2.1.1.jar -lat 29.65 -lon 91.13 -sta LHASA -o lhasa.blq
```

| 参数 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| `-lat` | 是 | — | 纬度（度） |
| `-lon` | 是 | — | 经度（度） |
| `-sta` | 否 | Station | 站名 |
| `-o` | 否 | otl.blq | 输出文件路径 |

## 7. 编程示例

### 7.1 提取BLQ系数并输出文件

```java
BlqExtractor extractor = new BlqExtractor();
double[][][] blq = extractor.extract(29.65, 91.13);

// 查看M2分潮径向振幅和相位
System.out.printf("M2: amp=%.4f mm, phase=%.4f deg%n",
    blq[0][0][0], blq[0][0][1]);

// 输出标准BLQ文件
BlqWriter.write("lhasa.blq", "LHASA", 29.65, 91.13, blq);
```

### 7.2 计算OTL位移时间序列

```java
BlqExtractor extractor = new BlqExtractor();

// 2026-09-24 00:00 ~ 01:00 UTC, 10秒间隔
double startMjd = 60936.0;  // MJD
double endMjd = 60936.0 + 1.0 / 24.0;  // +1小时
double intervalSec = 10.0;

double[][] disp = extractor.extractDisplacement(29.65, 91.13,
    startMjd, endMjd, intervalSec);

for (double[] epoch : disp) {
    System.out.printf("MJD=%.6f  E=%8.4f  N=%8.4f  U=%8.4f mm%n",
        epoch[0], epoch[1], epoch[2], epoch[3]);
}
```

### 7.3 批量生成多站BLQ文件

```java
BlqExtractor extractor = new BlqExtractor();

String[] names = {"LHASA", "LINZHI", "CHENGDU", "MENGDIGOU"};
double[] lats = {29.65, 29.65, 30.57, 29.50};
double[] lons = {91.13, 94.33, 104.07, 101.50};

for (int i = 0; i < names.length; i++) {
    double[][][] blq = extractor.extract(lats[i], lons[i]);
    BlqWriter.write(names[i].toLowerCase() + ".blq",
        names[i], lats[i], lons[i], blq);
}
```

## 11. 与rtklib-core的关系

本模块与 `rtklib-core` 完全独立，无编译或运行时依赖。

| 模块 | 职责 | 数据来源 |
|------|------|----------|
| `rtklib-otl` | 从FES2004模型直接生成BLQ系数/位移 | FES2004球谐系数（内置） |
| `rtklib-core` | PPP/RTK处理中使用BLQ系数做海潮改正 | 外部BLQ文件（如GOTIC2生成） |

`rtklib-core` 通过 `OtlReader.readblq()` 读取BLQ文件，`Tides.tidedisp()` 使用BLQ系数计算位移。本模块可作为BLQ文件的生成工具，但两个模块之间不存在代码级耦合。
