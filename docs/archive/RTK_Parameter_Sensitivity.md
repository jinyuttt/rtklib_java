# RTK参数敏感性分析

基于差数据组（基站A→测站A，2026-07-04，北斗4频）的实测对比，
量化各PrcOpt参数对FIX率的影响幅度，为不同站点配置调优提供依据。

---

## 测试条件

| 项目 | 值 |
|------|-----|
| 基线 | 基站A→测站A（差数据组，28天平均FIX率48%） |
| 日期 | 2026-07-04 |
| 系统 | 北斗（SYS_CMP） |
| 时段 | 17:00~23:59 |
| 基准配置 | static, nf=4, saastamoinen, arthres=4.0, minlock=20, minfix=20 |
| 基准FIX率 | 81.0% |

---

## 参数影响排序

| 排名 | 参数 | 影响幅度 | 方向 | 关键性 |
|------|------|---------|------|--------|
| 1 | 频点数(nf) | +68.7% | nf1→nf2 | 决定性 |
| 2 | 对流层模型(tropopt) | +40.6% | EST→SAAS | 极重要 |
| 3 | AR锁定计数(minlock) | +56.2% | 0→20 | 极重要 |
| 4 | 定位模式(mode) | +22.1% | KINEMA→STATIC | 重要 |
| 5 | 电离层模型(ionoopt) | -76.6% | BRDC→IFLC | 极重要（方向反） |
| 6 | AR ratio阈值(thresar) | -14.9% | 2→6 | 可靠性vs可用性 |
| 7 | AR最小FIX计数(minfix) | -8.8% | 10→20 | 中等 |
| 8 | 潮汐/PCV(tidecorr,posopt) | 0% | — | 短基线无影响 |

## 1. 频点数(nf) — 影响幅度 +68.7%

| nf | FIX率 | FIX | FLOAT | SINGLE | 说明 |
|----|-------|-----|-------|--------|------|
| 1 | 17.7% | 297 | 1377 | 1 | 单频无法消除电离层，模糊度几乎无法固定 |
| 2 | 80.4% | 1347 | 327 | 1 | 双频可估计电离层延迟，FIX率大幅提升 |
| **3** | **86.4%** | **1447** | **227** | 1 | **三频冗余观测最多，FIX率最高** |
| 4 | 81.0% | 1356 | 318 | 1 | 四频第4频点信号弱反而引入噪声 |

### 调优建议

- **北斗4频数据**：优先用 `nf=3`，第4频点(B1C)信号质量差会拖累整体
- **双频接收机**：`nf=2` 已经能获得80%+FIX率
- **单频**：几乎无法RTK固定，不建议

---

## 2. 对流层模型(tropopt) — 影响幅度 +40.6%

| tropopt | FIX率 | FIX | FLOAT | SINGLE | 说明 |
|---------|-------|-----|-------|--------|------|
| **SAASTAMOINEN** | **81.0%** | **1356** | **318** | 1 | 模型化，不估计额外参数 |
| EST | 40.4% | 677 | 995 | 3 | 估计天顶对流层残差，多1参数→收敛慢 |

### 调优建议

- **短基线(<10km)**：必须用 `SAASTAMOINEN`，不估计对流层参数
- **中长基线(10~50km)**：`EST` 或 `ESTG`，需要估计对流层残差
- EST模式多1个待估参数，在观测不足时显著增加模糊度收敛难度

---

## 3. AR锁定计数(minlock) — 影响幅度 +56.2%

| minlock | FIX率 | FIX | FLOAT | SINGLE | 说明 |
|---------|-------|-----|-------|--------|------|
| 0 | 24.8% | 415 | 1259 | 1 | 不等锁定就尝试固定，大量错固→holdamb锁死错误值 |
| 5 | 67.5% | 1130 | 544 | 1 | |
| 10 | 79.5% | 1332 | 342 | 1 | |
| **20** | **81.0%** | **1356** | **318** | 1 | 生产配置，保守 |
| 50 | 81.8% | 1370 | 304 | 1 | 过大延迟收敛，但差数据下差异不大 |

### 调优建议

- **差数据/多路径严重**：`minlock=20` 防止未收敛模糊度被错固
- **好数据/开阔环境**：`minlock=10` 更快进入FIX
- **minlock=0 绝对避免**：错固后holdamb会锁死错误整数值，后续历元全FLOAT

---

## 4. 定位模式(mode) — 影响幅度 +22.1%

| mode | FIX率 | FIX | FLOAT | SINGLE | 说明 |
|------|-------|-----|-------|--------|------|
| KINEMA | 58.9% | 987 | 687 | 1 | 动态模型，估计速度+加速度，状态向量大→收敛慢 |
| **STATIC** | **81.0%** | **1356** | **318** | 1 | 位置固定，状态向量最小→收敛快 |
| STATIC_START | 56.5% | 946 | 728 | 1 | 先STATIC后切KINEMA，切换时模糊度重新收敛 |

### 调优建议

- **静态监测站**：必须用 `STATIC`，状态向量最小，模糊度收敛最快
- **动态监测**：`KINEMA`，但FIX率会下降
- **STATIC_START**：切换KINEMA时模糊度重新收敛，实际效果不如纯STATIC

---

## 5. 电离层模型(ionoopt) — 影响幅度 -76.6%

| ionoopt | FIX率 | FIX | FLOAT | SINGLE | 说明 |
|---------|-------|-----|-------|--------|------|
| **BRDC** | **81.0%** | **1356** | **318** | 1 | 广播星历电离层改正 |
| IFLC | 4.4% | 73 | 1592 | 10 | 无电离层组合，噪声放大3倍+只剩1等效频点 |

### 调优建议

- **多频RTK(≥2频)**：必须用 `BRDC`，保留原始频点信息
- **IFLC对多频RTK有害**：组合后噪声放大，且只剩1个等效频点，模糊度无法固定
- **IFLC仅适合双频长基线**：>50km电离层不相关时，IFLC消除电离层一阶项

---

## 6. AR ratio阈值(thresar) — 影响幅度 -14.9%

| thresar | FIX率 | FIX | FLOAT | SINGLE | 说明 |
|---------|-------|-----|-------|--------|------|
| 2.0 | 92.6% | 1551 | 123 | 1 | 宽松，容易FIX但可能错固 |
| 3.0 | 86.8% | 1454 | 220 | 1 | 标准阈值 |
| **4.0** | **81.0%** | **1356** | **318** | 1 | 生产配置，保守 |
| 5.0 | 80.8% | 1354 | 320 | 1 | 更保守 |
| 6.0 | 77.7% | 1302 | 372 | 1 | 过于保守 |

### 调优建议

- **可靠性优先**（监测/变形）：`thresar=4.0~5.0`，降低错固风险
- **可用性优先**（施工/导航）：`thresar=2.0~3.0`，更多FIX历元
- **错固代价极大时**：`thresar=6.0`，但FIX率显著下降

---

## 7. AR最小FIX计数(minfix) — 影响幅度 -8.8%

| minfix | FIX率 | FIX | FLOAT | SINGLE | 说明 |
|--------|-------|-----|-------|--------|------|
| 1 | 88.3% | 1479 | 195 | 1 | 1次FIX就hold，风险高 |
| 5 | 86.9% | 1455 | 219 | 1 | |
| **10** | **89.8%** | **1504** | **170** | 1 | **最优：更早hold住模糊度** |
| 20 | 81.0% | 1356 | 318 | 1 | 生产配置，偏保守 |
| 50 | 80.9% | 1355 | 319 | 1 | |

### 调优建议

- **差数据**：`minfix=10` 效果最好（89.8%），更早hold住模糊度减少FLOAT
- **好数据**：`minfix=20` 更安全，防止偶然错固被hold
- **注意**：minfix控制何时开始holdamb，更早hold→更早锁住模糊度→减少FLOAT打断

---

## 8. 潮汐改正+天线PCV — 影响幅度 0%

| 配置 | FIX率 |
|------|-------|
| 无潮汐无PCV | 81.0% |
| 有潮汐无PCV | 81.0% |
| 无潮汐有PCV | 81.0% |
| 有潮汐有PCV | 81.0% |

### 调优建议

- **短基线(<10km)**：潮汐和PCV改正量<1cm，对FIX率无影响
- **长基线(>50km)**：潮汐改正可达cm级，建议开启
- **高精度要求(mm级)**：PCV改正必要，但影响的是精度而非FIX率

## 不同站点类型的推荐配置

### 短基线静态监测（<10km，最常见）

```
mode     = STATIC
nf       = 3 (北斗4频数据) 或 2 (双频)
tropopt  = SAASTAMOINEN
ionoopt  = BRDC
thresar  = 4.0
minlock  = 20
minfix   = 10
tidecorr = 0 (短基线无影响)
posopt   = [0,0,0] (短基线无影响)
```

### 中长基线（10~50km）

```
mode     = STATIC
nf       = 3
tropopt  = EST
ionoopt  = BRDC
thresar  = 3.0
minlock  = 10
minfix   = 10
tidecorr = 1
posopt   = [1,1,1]
```

### 动态监测（流动站移动）

```
mode     = KINEMA
nf       = 3
tropopt  = SAASTAMOINEN
ionoopt  = BRDC
thresar  = 3.0
minlock  = 10
minfix   = 5
tidecorr = 0
posopt   = [0,0,0]
```

### 差数据/多路径严重环境

```
mode     = STATIC
nf       = 3
tropopt  = SAASTAMOINEN
ionoopt  = BRDC
thresar  = 4.0
minlock  = 20        # 严防错固
minfix   = 10
tidecorr = 0
posopt   = [0,0,0]
# 优化项建议
enableIggiii = true   # 抗差估计剔除粗差
enableSnrMedian = true # SNR定权降低弱信号权重
```

## 优化项在不同配置下的效果

| 优化项 | static+saas | kinema+est | 差数据 | 说明 |
|--------|-------------|------------|--------|------|
| 自适应Q | 无效 | **有效** | 待验证 | 仅动态模式下Q缩放有实质影响 |
| IGGIII | +3.5% | 待测试 | **有效** | 剔除粗差观测，减少模糊度扰动 |
| SNR中位数 | 无效 | **有效** | 待验证 | 配置差时权重不合理，SNR定权可弥补 |
| 参考星重选 | 无效 | 待测试 | 待验证 | 参考星稳定时无触发条件 |
| 模糊度锚定 | 无效 | 待测试 | 待验证 | 需连续FIX≥minfix才holdamb，FLOAT频繁打断时无效 |
| 电离层梯度 | 无效(短基线) | 待测试 | 无效 | 短基线双差可消除电离层 |

### 关键发现

1. **优化项效果高度依赖基准配置**：在正确配置(static+saas+4频)下，大部分优化项无额外增益
2. **优化项主要针对差配置或差数据**：当基准配置不合理时(kinema+est+3频)，SNR定权等优化项效果显著
3. **IGGIII是最稳健的优化项**：在正确配置下仍有+3.5%增益，因为粗差观测在任何数据中都存在
4. **自适应Q仅动态模式有效**：static模式下dynamics=0，Q缩放对位置过程噪声影响微弱
5. **基站稳定性是独立关注点**：参数调优解决的是FIX率问题，基站移动是另一种故障源，需独立检测（见`BaseStationMonitor`）
